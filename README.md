# tg-shop-bot

Telegram-бот магазина на aiogram 3: каталог, корзина, оформление заказа,
админ-панель и уведомления. Данные в SQLite, запускается одной командой.

Подходит для кофейни, кондитерской, магазина мерча, сервиса с заявками:
сценарий меняется под клиента, а не наоборот.

## Как это выглядит для покупателя

```
/start
  ├─ Каталог ──► категории ──► товары ──► карточка ──► [+ в корзину]
  ├─ Корзина ──► состав и сумма ──► Оформить ──► имя ──► телефон ──► «Заказ №12 принят»
  └─ Доставка и оплата
```

Админ получает сообщение с составом заказа и двумя кнопками:
`Подтвердить` / `Отменить`. Клиенту приходит уведомление о смене статуса.

## Что внутри

| Файл | Назначение |
|---|---|
| `bot.py` | точка входа: сборка Dispatcher, polling |
| `config.py` | настройки из `.env` (токен, админы, название) |
| `db.py` | SQLite через aiosqlite: каталог, корзина, заказы, статистика |
| `keyboards.py` | инлайн-клавиатуры |
| `handlers/catalog.py` | категории → товары → карточка → корзина |
| `handlers/cart.py` | корзина, FSM-оформление заказа, уведомление админу |
| `handlers/admin.py` | `/admin`, добавление товаров, скрытие, смена статуса |
| `tests/test_db.py` | тесты слоя данных на временной БД |

## Запуск

```bash
git clone https://github.com/kuruma4/tg-shop-bot
cd tg-shop-bot
pip install -r requirements.txt
cp .env.example .env        # Windows: copy .env.example .env
# вписать BOT_TOKEN из @BotFather и свой ADMIN_IDS
python bot.py
```

При первом старте база создаётся сама и наполняется демо-каталогом
(3 категории, 4 товара) — можно сразу пройти весь путь покупателя.

## Команды админа

```
/admin                       — сводка: заказы, выручка, последние 5 заказов
/add_category Кофе           — новая категория
/add_product 1|Раф|270       — товар: категория|название|цена в рублях
/hide 12                     — скрыть товар из каталога
```

## Технические решения

- **Цены в копейках.** Никакой плавающей точки в деньгах — только целые.
- **Параметризованные запросы.** Пользовательский ввод не попадает в SQL.
- **Корзина в БД, а не в памяти.** Перезапуск бота не теряет заказы.
- **Транзакция при оформлении.** Заказ и его позиции создаются вместе;
  корзина очищается только после успешной записи.
- **FSM для диалога.** Имя и телефон спрашиваются по шагам, номер валидируется.

## Что нужно доработать под клиента

- **Онлайн-оплата.** Telegram Payments подключается за 20 минут
  (`PAYMENT_TOKEN` из BotFather → Payments: отправка инвойса вместо уведомления
  админу). Нужен эквайринг у клиента.
- **Доставка.** Сейчас фиксированные условия в тексте; адреса и зоны —
  отдельная задача.
- **Хостинг.** VPS + systemd, либо любой сервер с Python 3.10+.
